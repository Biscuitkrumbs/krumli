# Krumli landing page

Files:
- `index.html`
- `styles.css`

This is a static landing page, so it can be hosted on GitHub Pages, Cloudflare Pages, or almost any static host.

Before publishing:
1. If `hello@krumli.com` is not configured yet, remove or change that email link.
2. Change `Armidale, Australia` if you don't want a location shown publicly.
3. All main styling is centralized in the `:root` variables at the top of `styles.css`.
